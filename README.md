# likelion

멋쟁이사자처럼 백엔드 학습 초기에 만든 Spring Boot 실습 저장소입니다. 현재 코드는 기본 애플리케이션 실행 구조와 간단한 `Hello` 클래스 중심으로 구성되어 있습니다.

## 기술 스택

- Java
- Spring Boot
- Maven

## 실행 방법

```bash
./mvnw spring-boot:run
```

## 현재 구현 범위

- Spring Boot 프로젝트 기본 구조 생성
- 애플리케이션 진입점 작성
- 간단한 Java 클래스 실습

## 보완할 점

- 아직 실제 웹 API나 화면 기능은 없습니다.
- Controller, Service, Repository 계층을 추가하면 백엔드 프로젝트 형태가 더 분명해집니다.
- 학습 기록으로는 충분하지만, 포트폴리오용으로 보여주려면 기능 구현과 README 예시를 더 보강해야 합니다.
